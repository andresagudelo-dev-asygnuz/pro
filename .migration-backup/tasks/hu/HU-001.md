# HU-001 - Registro con roles (jugador / promotor)

## Historia
Como visitante sin cuenta en PRO
Quiero registrarme seleccionando mi rol (jugador, promotor, o ambos)
Para acceder a las funcionalidades que correspondan a mi rol dentro de la plataforma.

## Criterios de aceptación (GIVEN/WHEN/THEN)
1. Registro válido con rol jugador
- GIVEN un visitante sin cuenta
  WHEN completa el formulario de registro con datos válidos y rol `jugador`
  THEN el sistema crea la cuenta, le asigna el rol `jugador` y lo redirige al flujo de verificación de edad (HU-002).

2. Registro válido con rol promotor
- GIVEN un visitante sin cuenta
  WHEN completa el formulario de registro con datos válidos y rol `promotor`
  THEN el sistema crea la cuenta, le asigna el rol `promotor` y lo redirige al panel de gestión de torneos.

3. Registro con doble rol (jugador + promotor)
- GIVEN un visitante sin cuenta
  WHEN selecciona ambos roles en el registro
  THEN el sistema crea la cuenta con ambos roles activos y aplica las reglas de onboarding del rol `jugador` primero (verificación de edad) antes de habilitar el panel de promotor.

4. Datos inválidos o faltantes
- GIVEN un visitante completando el registro
  WHEN envía el formulario con datos incompletos o inválidos (email mal formado, contraseña débil, rol no seleccionado)
  THEN el sistema muestra errores específicos por campo y no crea la cuenta.

## Dependencias
- RF-001 (`docs/01-requisitos-funcionales.md`).
- Depende en cadena: HU-002 (verificación de edad) se ejecuta inmediatamente después del registro para el rol jugador.
