## Sesión tarde/noche — HU-005 bug fix + HU-006 Resultados+Standings

### HU-005 bug fix (commit `f776397`, PR #29)
- **🔴 crítico**: `findUnverifiedUsers` consultaba `age_verifications` directamente desde el browser; la RLS `age_verifications_read_self` solo permite `auth.uid() = user_id`, así que el capitán solo leía su propia verificación y los demás miembros del equipo aparecían siempre como no verificados → toda inscripción de equipo con ≥2 miembros fallaba.
- **Fix**: función SQL `public.find_unverified_users(uuid[]) returns uuid[]` con `SECURITY DEFINER` (bypasea RLS), grant solo a `authenticated`. TS ahora llama `supabase.rpc('find_unverified_users', …)`. Mismo patrón que `ensure_verification_aprobada` del Sprint 1.
- **Tests**: 4 tests actualizados para mockear `.rpc()`; +1 test nuevo para el short-circuit con lista vacía. Suite **140/140**.
- **CI**: PR #29 verde 5/5 (lint+build, secret-scan, Vercel, Vercel preview, Devin Review).
- **Retargeting**: una vez mergeado PR #28 a `main`, PR #29 quedó apuntando a una rama eliminada; retargeteé a `main` vía `gh pr edit` (sin conflictos, mergeable).
- **2 🔴 adicionales de Devin Review** (reportados al usuario, quedan para Sprint 6):
  1. `sync_tournament_slots_on_status_change` no valida estado del torneo al re-confirmar → permite volver a `confirmada` después de `cerrado_inscripciones`.
  2. RLS `tr_update_self_or_owner` sin `WITH CHECK` por rol → jugador puede auto-promoverse de `lista_espera` a `confirmada`.
