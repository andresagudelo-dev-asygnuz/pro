# Test plan · HU-004 Crear y gestionar torneos (RF-003)

Historia: `tasks/hu/HU-004.md`.
Migración canónica: `apps/web/supabase/migrations/20260425140000_g4_sprint3_tournaments.sql`.

## Scope

- `tournaments(id, owner_id, name, format, slots, slots_filled, location, start_date, end_date, status, categories, …)`.
  - `format ∈ {liga, eliminatoria, fase_grupos_eliminatoria}`.
  - `status ∈ {borrador, abierto_inscripciones, cerrado_inscripciones, cancelado, finalizado}`.
- RLS:
  - Lectura pública para torneos no-`borrador`.
  - `tournaments_owner_write_self`: solo owner puede insert/update/delete.
- Rutas:
  - `/tournaments` — listado público (excluye borradores ajenos).
  - `/tournaments/mine` — listado del promotor.
  - `/tournaments/new` — formulario creación.
  - `/tournaments/[id]` — detalle (para inscritos, promotor, público).
- Transiciones válidas de status: `borrador → abierto_inscripciones →
  cerrado_inscripciones → finalizado` (o `cancelado` en cualquier punto).
  `publishTournament()` enforce la primera.
