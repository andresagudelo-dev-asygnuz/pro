# HU-004 - Creación y gestión de torneos (promotor)

## Historia
Como promotor autenticado
Quiero crear y configurar un torneo de fútbol con datos mínimos (nombre, formato, cupos, ubicación, fechas, categorías)
Para publicarlo y permitir que jugadores o equipos se inscriban.

## Criterios de aceptación (GIVEN/WHEN/THEN)
1. Creación de torneo con datos mínimos
- GIVEN un promotor autenticado
  WHEN envía el asistente de creación de torneo con los datos mínimos válidos (nombre, formato, cupos, ubicación, fecha)
  THEN el sistema crea el torneo en estado `borrador` y lo muestra en el panel del promotor.

2. Publicación del torneo
- GIVEN un promotor con un torneo en estado `borrador`
  WHEN publica el torneo
  THEN el sistema pasa el torneo a estado `abierto a inscripciones`, lo hace visible en el listado público y habilita el flujo de inscripción (HU-005).

3. Edición de torneo en borrador
- GIVEN un promotor con un torneo en estado `borrador`
  WHEN edita los datos del torneo
  THEN el sistema persiste los cambios sin notificar a terceros (aún no hay inscritos).

4. Edición de torneo publicado
- GIVEN un promotor con un torneo ya publicado y con inscritos
  WHEN edita datos no-estructurales (descripción, banner)
  THEN el sistema persiste los cambios y registra un evento de auditoría.
  AND WHEN intenta editar datos estructurales (formato, cupos a la baja, fechas ya pasadas) sin justificación THEN el sistema pide confirmación y, si confirma, notifica a los equipos inscritos.

5. Restricción por rol
- GIVEN un usuario autenticado sin rol promotor
  WHEN intenta acceder al asistente de creación de torneo
  THEN el sistema bloquea el acceso y muestra mensaje de permisos.
